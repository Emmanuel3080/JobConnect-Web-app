# JobConnect 💼

JobConnect is a full-stack job recruitment platform built with the **MERN Stack**. It connects job seekers with employers, allowing candidates to discover job opportunities while employers can create and manage job listings.

## 🚀 Features

### 👤 Job Seekers

* Create and manage an account
* Browse available job opportunities
* Search and filter jobs
* View detailed job information
* Apply for jobs
* Manage applications

### 🏢 Employers

* Create and manage job listings
* View available applicants
* Manage posted jobs
* Review candidate applications

### 🔐 Authentication & Security

* User registration and login
* JWT-based authentication
* Protected routes
* Password hashing with bcrypt
* Role-based access for users and employers

## 🔄 How It Works

1. Users create an account and log in.
2. Job seekers browse available job opportunities.
3. Candidates view job details and submit applications.
4. Employers create and manage job postings.
5. Employers review applications from candidates.
6. Authentication and protected routes keep user data and actions secure.

## 🎯 Project Goals

JobConnect was developed to provide a simple and accessible platform for connecting job seekers with employment opportunities while giving employers tools to manage their recruitment process.

The project also demonstrates practical implementation of:

* Full-stack web development
* RESTful APIs
* Authentication and authorization
* Database design
* File uploads
* Frontend state management
* Responsive UI development
* Deployment
